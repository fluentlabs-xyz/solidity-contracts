How a floor is decided

1. climb() binds you to a drand round whose beacon does not exist yet — the oracle refuses to hand out a round that is already public.

2. About 6 seconds later drand emits that beacon and a publisher puts it on chain, signature-checked against drand quicknet's key.

3. The beacon is folded with your own address, so every climber waiting on that round gets a different value — one can fall while another holds.

4. resolve() settles the floor: value % 4 != 0 holds — 3 chances in 4. Otherwise the whole run is lost.

5. bank() turns N standing floors into N×(N+1)/2 points. Break-even is the sixth floor: banking six is worth 21, and risking it for a seventh is worth 0.75 × 28 — the same 21.
